# ExtremeSurvival – Ward Collapse Music

The official music resource pack for the ExtremeSurvival Minecraft server.

## 🎵 Soundtrack

This pack contains five custom music tracks:

1. Boss Battle Music
2. Determined Pursuit
3. Battle Theme A
4. The Final Battle
5. Evil Approach

## Features

- Minecraft Java Edition 26.3 compatibility.
- Five OGG Vorbis audio tracks.
- Custom ExtremeSurvival sound events.
- Designed for server-wide Ward Collapse events.
- Integrated with ExtremeSurvivalCore 1.2.47 and later.

## Installation

Players can download the resource pack automatically
when joining the ExtremeSurvival server.

Accept the resource-pack prompt to hear the custom music.
